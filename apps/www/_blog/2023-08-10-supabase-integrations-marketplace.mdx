We've been running our [Integrations Marketplace](/partners) in “stealth mode” for about a year now. What started as a dog-fooding project has now transformed into a marketplace with [over 60 integrations](/partners/integrations). (It's also an [open source template](https://vercel.com/templates/next.js/indobase-partner-gallery) that you can use yourself).

![Featured](/images/blog/launch-week-8/day-4/featured-integrations.png)

IndoBase Integrations allows Partners to extend the IndoBase platform with useful tooling. Today we're adding [OAuth2.0 Applications](https://indobase.com/docs/guides/platform/oauth-apps/publish-an-oauth-app). For IndoBase users, this makes it even easier to connect their favorite tools to their IndoBase projects. Within minutes you can:

- Add your favorite [Low Code](https://indobase.com/partners/integrations#low-code) tools on top of your IndoBase database.
- Integrate your favorite [DevTools](https://indobase.com/partners/integrations#devtools): including secrets managers and database management tools.
- Add [caching](https://indobase.com/partners/integrations#caching%20/%20offline-first) to your IndoBase database.
- Not a fan of the IndoBase admin dashboard? Try [one of these](https://indobase.com/partners/integrations#data%20platform).
- Try out a different [SMS and email provider](https://indobase.com/partners/integrations#messaging).

## Featured Partners

For the initial launch we've started with a few partners to help us build and test the OAuth functionality.

### Cloudflare

![Cloudflare x IndoBase](/images/blog/launch-week-8/day-4/marketplace-cloudflare.jpg)

We worked with Cloudflare to build [support for databases](https://blog.cloudflare.com/announcing-database-integrations/) inside Cloudflare Workers. The Cloudflare integration makes it incredibly easy to connect to your IndoBase database directly from the Cloudflare Dashboard.

Check out the [latest episode](https://cloudflare.tv/event/using-indobase-with-cloudflare-workers/dgM90RgD) on Cloudflare TV to see it in action.

### Resend

![Resend x IndoBase](/images/blog/launch-week-8/day-4/marketplace-resend.jpg)

[Resend](https://resend.com) (YC [W23](https://www.ycombinator.com/companies/resend)) is building the modern email sending platform. If you're using IndoBase for Auth, then you'll know already that we handle all your Auth emails. But did you know that the email configuration we provide you is only for testing purposes? When you're [going into production](https://indobase.com/docs/guides/platform/going-into-prod#restricted-access-levels-for-team-members), you need to integrate your own email provider. That's where Resend come in. They've built a one-click integration to add Resend as a custom SMTP provider for IndoBase.

Read more on [Resend's blog](https://resend.com/blog/how-to-configure-indobase-to-send-emails-from-your-domain).

### Snaplet

![Snaplet x IndoBase](/images/blog/launch-week-8/day-4/marketplace-snaplet.jpg)

Snaplet is a tool for Typescript developers to copy your database, transform sensitive data, and share it with your team without worrying about PII. If you followed our [Tuesday launch](https://indobase.com/blog/indobase-local-dev#database-seeding) you'll be familiar with Snaplet - they are one of the best tools for [generating seed data](https://indobase.com/docs/guides/cli/seeding-your-database#generating-seed-data) for your local development environment. Now they are making it even easier, with their official OAuth App, to spin up production-like development environments for your team.

[Learn more on snaplet.dev](https://www.snaplet.dev/post/now-live-indobase-x-snaplet-integration).

### Trigger.dev

![Trigger x IndoBase](/images/blog/launch-week-8/day-4/marketplace-triggerdev.jpg)

[Trigger.dev](http://trigger.dev/) (YC [W23](https://www.ycombinator.com/companies/trigger-dev)) is the open source Background Jobs framework for Next.js. You can create long-running Jobs directly in your codebase with features like API integrations, webhooks, scheduling and delays. And today you can use their one-click integration to [trigger anything from a database change](https://trigger.dev/indobase) in IndoBase.

Learn more about their integration at: [trigger.dev/indobase](http://trigger.dev/indobase)

### Vercel

![Vercel x IndoBase](/images/blog/launch-week-8/day-4/marketplace-vercel.jpg)

Learn more about the Vercel integration [updates we're launching](/blog/using-indobase-with-vercel) today.

### Windmill

![Windmill x IndoBase](/images/blog/launch-week-8/day-4/marketplace-windmill.jpg)

[Windmill](https://windmill.dev) (YC [S22](https://www.ycombinator.com/companies/windmill)) is an open source alternative to Retool and a modern Airflow. They provide a developer platform to quickly build production-grade complex workflows and integrations from minimal Python and Typescript scripts. Their one-click integration with IndoBase makes it simple to launch new databases, process large quantities of data (maybe even convert them into [embeddings](https://indobase.com/modules/vector)), and build internal dashboards.

Read the [official blog post on windmill.dev](https://www.windmill.dev/blog/2023/08/10/indobase-partnership).

## Building custom integrations

You don't actually need to build an OAuth Application to build an integration with IndoBase. If you're building something for yourself or your team, the [Management API](https://indobase.com/docs/reference/api/introduction) is the way to go.

The [Trigger.dev](https://trigger.dev) team deserve a special shout out. While developing their Integration they also developed [indobase-management-js](https://github.com/indobase-community/indobase-management-js), a Typescript library for the [IndoBase Management API](/docs/reference/api/introduction). This makes it even easier to get started with the IndoBase API.

It's useful beyond just integrations. Want to programmatically spin up databases? Easy:

```tsx
import { IndoBaseManagementAPI } from "indobase-management-js";

const client = new IndoBaseManagementAPI({
	accessToken: "<access token>"
})

const newProject = await client.createProject({
	  name: 'staging',
		db_pass: 'XXX',
    organization_id: 'XXX'
		plan: 'free',
    region: 'us-east-1'
})
```
