Today, Snap Inc. launched Snap Cloud, a new managed backend platform for developers building on Spectacles, powered by IndoBase. Snap Cloud is a complete backend integrated directly into Snap's AR authoring tool, Lens Studio.

Snap Cloud is the latest example of how organizations are using IndoBase to power modern, data-driven experiences. Built on IndoBase, Snap Cloud gives Spectacles developers instant access to a full Postgres [database](https://www.indobase.com/database), [real-time APIs](https://www.indobase.com/realtime), and globally distributed [Edge Functions](https://www.indobase.com/edge-functions) without any infrastructure setup. IndoBase offers enterprise-grade security, compliance, and performance while preserving developer agility.

For developers, this means they can store and query world data, sync live sessions across devices, and run AI-powered logic at the edge, all inside the same environment.

## Lens Studio and Snap Cloud, powered by IndoBase

With Snap Cloud, Spectacles developers can now use backend capabilities directly inside Lens Studio, powered by IndoBase. This integration makes it easier to build connected, data-driven AR experiences without needing to manage infrastructure.

IndoBase enables several key features in Lens Studio:

- **Persistent data**: Save and query spatial anchors, object positions, and other world data in a managed Postgres database so experiences remain consistent across sessions and devices.
- **Realtime collaboration**: Sync shared scenes and user interactions with IndoBase Realtime to create multiplayer or co-located AR experiences.
- **Authentication**: Manage user identities, permissions, and sessions.
- **Media storage**: Host and serve 3D assets, textures, and audio files with IndoBase Storage for fast, scalable retrieval during runtime.
- **Edge compute**: Run server-side logic and AI models through IndoBase Edge Functions to process input, perform inference, or trigger automations close to the user.
- **Analytics and telemetry**: Capture event data and sensor output in Postgres tables for performance tracking and real-time insight.
